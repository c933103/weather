# East Asia Weather Daily

Numerical forecast collection for Hong Kong, Taipei, Tokyo Minato Ward and Takamatsu.

This repository hosts the 05:00 JST collection pass. The existing single ChatGPT automation remains responsible for calculation, charting and the 06:00 JST report.

Collection is not considered complete merely because a request or workflow succeeds. Per-field numerical coverage, source freshness and unresolved hazards are recorded explicitly.
